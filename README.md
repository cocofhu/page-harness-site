# page-harness site

The homepage for [page-harness](https://www.npmjs.com/package/page-harness), published at <https://cocofhu.github.io/page-harness-site/>.

Plain static files, no build step. Preview locally with any static server:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

The dock in the bottom-right corner is a scripted demo of the real overlay; it doesn't talk to any agent.

Brand logos come from [simple-icons](https://simpleicons.org) (CC0) and remain trademarks of their owners.
