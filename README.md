# page-harness site

The homepage for [page-harness](https://www.npmjs.com/package/page-harness), published at <https://cocofhu.github.io/page-harness-site/>.

Plain static files, no build step. Preview locally with any static server:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

The page is one scroll-driven shot: the camera moves through a rebuilt demo app while the overlay is scripted from scroll progress, and the last scene hands the dock to the visitor. `assets/f-compare.webp` (a real capture) is only used as the social preview image.

Brand logos come from [simple-icons](https://simpleicons.org) (CC0) and remain trademarks of their owners.
